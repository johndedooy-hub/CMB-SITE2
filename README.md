# CMB SITE2

Uitgebreide PHP-radiosite, bronversie **CMB SITE2 - 1611 2028 [2]**. De eigenlijke website staat onder `CMB-TV-READY/`. Aanvullende regio- en infobestanden staan in afzonderlijke mappen.

De originele volledige release en instellingen blijven in Google Drive > CMB PROJECTEN > CMB SITE2. Deze GitHub-repository is openbaar: geen productieconfiguraties, wachtwoorden, tokens, caches of persoonlijke uploads opnemen.

Zie `CMB-TV-READY/TV-READY-INSTALL.md` voor de oorspronkelijke installatie-instructies. CMB STATIC is een apart project.
