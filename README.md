# CMB SITE2

Uitgebreide PHP-radio- en tv-website. Bronversie: **CMB SITE2 - 1611 2028 [2].zip** (16 november 2026). De oorspronkelijke release is bewaard in Google Drive > CMB PROJECTEN > CMB SITE2.

De archiefstructuur blijft herkenbaar: `CMB-TV-READY/` bevat de eigenlijke website, met aanvullende regiobestanden en voorbeeldconfiguraties ernaast. Voor installatie lees `CMB-TV-READY/TV-READY-INSTALL.md`.

**Belangrijk:** deze repository is openbaar; geen API-sleutels, wachtwoorden, runtime-data, caches of persoonlijke uploads committen. Bewaar bestaande `cmb-data` en `cmb-uploads` op hosting bij upgrades. Dit project blijft gescheiden van CMB STATIC.
